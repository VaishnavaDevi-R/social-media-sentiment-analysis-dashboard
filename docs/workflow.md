# ⚙️ Project Workflow

## Step 1: Data Collection
- Synthetic or CSV-based social media comments

## Step 2: Data Cleaning
- Remove special characters
- Convert to lowercase
- Remove stopwords

## Step 3: Feature Extraction
- Convert text into numerical form using TF-IDF

## Step 4: Model Training
- Train Random Forest classifier
- Learn sentiment patterns

## Step 5: Prediction
- Predict sentiment for new input text

## Step 6: Visualization
- Display results in Streamlit dashboard

## Step 7: Insights
- Generate charts and business insights
