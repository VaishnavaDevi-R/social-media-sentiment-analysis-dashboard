# 📊 Social Media Sentiment Analysis Dashboard

## 🔍 Overview
This project is an end-to-end machine learning system that analyzes social media text and classifies it into:
- Positive 😊
- Negative 😡
- Neutral 😐

It includes:
- Data preprocessing pipeline
- TF-IDF feature extraction
- Random Forest classification model
- Interactive Streamlit dashboard

---

## 🎯 Objective
To build a real-world analytics system that helps organizations understand customer sentiment and make data-driven decisions.

---

## 🧠 Key Features
- Real-time sentiment prediction
- Batch analysis using CSV files
- Confidence scoring for predictions
- Interactive charts and visualizations
- Keyword extraction and word cloud
- Business insights generation

---

## 🛠 Tech Stack
- Python
- Pandas, NumPy
- Scikit-learn
- NLTK
- Streamlit
- Plotly

---

## 📈 Outcome
This system simulates how companies monitor customer feedback, product reviews, and public opinion in real time.
